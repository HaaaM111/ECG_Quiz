# ECG_Quiz · 心电图识别训练（护理版）

面向护理人员的心电图识别训练工具，单文件 HTML 应用，**离线可用、无需安装、无需联网**。

## 功能

- **练习模式**：按难度（基础 / 进阶 / 高危）和题型（波形识别 / 临床情境）自由筛选刷题，答题后即时反馈知识点与护理要点
- **考核模式**：限时交卷、自动计分评等（≥60 及格线），未作答题目按答错计分
- **错题本**：答错题目自动收录，支持错题重练与一键清空
- **统计**：累计答题数、正确率、各心律答题情况
- **图鉴**：18 种心律的波形速查与一句话识别要点

## 题库覆盖（18 种心律）

| 类别 | 心律 |
| --- | --- |
| 窦性 | 正常窦性心律、窦性心动过速、窦性心动过缓 |
| 心律失常 | 房性早搏、室性早搏、心房颤动、心房扑动 |
| 心动过速 / 扑颤 | 室上速、室速、心室颤动 |
| 传导阻滞 | 一度 AVB、二度Ⅰ型 AVB、二度Ⅱ型 AVB、三度 AVB |
| 束支阻滞 | 左束支阻滞、右束支阻滞 |
| 危急重症 | 急性心梗（STEMI）、心搏停止 |

## 快速开始

1. 直接用浏览器打开 `心电图练习.html` 即可使用（双击文件）
2. 无需安装任何软件，单文件即整个应用
3. 数据仅保存在本机浏览器 `localStorage`（键 `ecg_quiz_v1`），清除浏览器数据即重置

## 免责声明

本工具波形为示意性 SVG 绘制（按 25mm/s、10mm/mV 标准比例示意），用于识别特征训练，**不构成真实心电图诊断，不得用于临床诊断或治疗决策**。临床心电图判读请以设备原始记录与医生诊断为准。

## 开发者扩展

文件内附「开发者速览」注释（页面底部），关键扩展点：

- **题库**：`QUESTIONS` 数组，照抄任一条目增删改题目（`type` / `key` / `diff` / `prompt` / `options` / `answer` / `recognize` / `nursing`）
- **波形**：`rhythmPath()` 的 switch 分支，每行一种心律，可调频率（bpm）、PR 间期、ST 抬高等参数；新增心律只需加一个 case
- **图鉴**：`ATLAS_ORDER` 控制显示顺序，`ATLAS_SNIPPET` 为速查一句话
- **配色**：`:root` 中的 CSS 变量（`--ecg` 心电红、`--ink` 主文字等），改色值即整体换肤

## 技术栈

原生 HTML + CSS + JavaScript，无任何外部依赖。
